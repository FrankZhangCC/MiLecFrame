# MiLecFrame 宣传视频 — 分镜 & 动态预演设计

> **用途**：After Effects 制作风格参考与分镜脚本  
> **成片时长**：约 **52 秒**（可裁 45s / 扩 60s，见附录 B）  
> **叙事弧**：一张照片 → 读取参数 → 映射信息 → 样式排版 → 切换样式 → 自定义样式  
> **风格关键词**：Apple 式简约 · 产品即主角 · 留白呼吸 · 精密微动效 · 克制转场

---

## 0. 一句话概念

> **「一张照片，读懂它的全部故事。」**  
> 从原片静默出现开始，信息被「唤醒」、被「翻译」、被「穿上衣服」，最终证明：同一张照片，可以有无限种表达。

全片不出现鼠标、不出现复杂 GUI 全屏、不堆功能清单——只让**照片本身**完成一次从「原片」到「成品」的蜕变。

## 1. 视觉风格圣经（Style Bible）

### 1.1 色彩系统

| 角色 | 色值 | 用法 |
|------|------|------|
| 舞台底色 A（主） | `#F5F5F7` | 主叙事段背景（Apple 产品页灰白） |
| 舞台底色 B（暗） | `#1D1D1F` | 开场/收尾/强调段（深空黑） |
| 纯白 | `#FFFFFF` | 卡片、投影承载面、文字反白 |
| 主文字 | `#1D1D1F` | 深底反白用 `#F5F5F7` |
| 次级文字 | `#86868B` | 标签、注释、EXIF 键名 |
| 品牌强调 | `#0071E3` | 极少量：光标、进度、关键节点高亮 |
| 数据金 | `#EFC354` / `#703C04` | 呼应 InfoCard 样式的金色标签（仅参数段点缀） |
| 成品框内 | 随样张照片 | 照片是唯一「彩色源」，UI 层保持无彩/极低饱和 |

**铁律**：除照片与品牌蓝/数据金外，全片 UI 层 **零彩色**。饱和度只属于内容，不属于界面。

### 1.2 字体系统

| 用途 | 字体 | 字重 | 字距 |
|------|------|------|------|
| 主标题 / Slogan | SF Pro Display / 苹方 SC（备选 Inter + 思源黑体） | Semibold | `-2%` |
| 功能短语 | 同上 | Medium | `0%` |
| 数据标签（FL/AP…） | SF Mono / JetBrains Mono | Regular | `+4%` |
| 数值（35mm / f/1.4） | SF Pro Text | Medium | `0%` |
| 极小注释 | SF Pro Text | Regular | `+2%` |

- 中英混排：中文略小于英文约 2%，基线对齐。
- **禁止**描边字、立体字、渐变字、投影字（照片内样式的字除外）。

### 1.3 几何与留白

| 参数 | 值 |
|------|-----|
| 安全边距 | 画幅短边 8% |
| 元素最小间距 | 24 px @1080p（≈ 短边 2.2%） |
| 圆角：卡片 | 16–24 px @1080p（大容器 28 px） |
| 圆角：胶囊/标签 | 全圆角（height/2） |
| 阴影 | 唯一规范：`0 24 48 rgba(0,0,0,0.08)` + `0 2 4 rgba(0,0,0,0.04)`；暗底用 `0 24 48 rgba(0,0,0,0.45)` |
| 照片圆角 | 0（原片锐利）或 12 px（成品卡） |

### 1.4 动效物理（AE 关键）

全部位移/缩放使用 **弹簧（Spring）** 而非线性缓动：

| 参数 | 建议 |
|------|------|
| 弹簧预设 | Overshoot 8–12%，无二次回弹（临界阻尼略欠） |
| 入场时长 | 400–700 ms |
| 出场时长 | 250–350 ms（更快，决绝） |
| 缓动曲线（无弹簧时） | `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint） |
| 交叉溶解 | 200–300 ms，禁止叠化超过 400 ms |
| 缩放聚焦 | `scale 0.96 → 1.00` 或 `1.04 → 1.00`（永不用 0→1 硬弹） |
| 模糊转场 | 高斯 0→12→0 px，与 scale 同步，仅用于段落切换 |
| 逐字/逐词显形 | opacity + y `+12px→0`，stagger 30–50 ms |

**禁止**：翻转、3D 轨道旋转、粒子爆炸、故障风 Glitch、强景深 DOF 切换、快速 whip pan。

### 1.5 镜头语言

- 景别：以 **中景/特写产品对象** 为主，避免大远景空镜。
- 运镜：极缓慢 push-in（scale 1.00→1.04，整段 4–6 s）或完全静止；**不用**摇移。
- 轻微视差：UI 元素相对照片位移速度 0.85×，营造「浮在上方」的玻璃层。
- 照片始终是画面主角，UI 是「注释」不是「截图」。

## 3. 分镜脚本（逐镜）

### S1 · 静默之像（0:00–0:06）

**画面**
- 背景：`#F5F5F7` 纯色，无渐变（或极淡径向亮斑 `#FFFFFF` 中心 3% 亮度差）。
- 中央：一张 **3:2 横构图样张**（建议城市街景或建筑，细节丰富但色调克制），尺寸约占画幅高度 55%，带标准产品阴影。
- 无文字，无 UI。

**动态**
| t | 动作 |
|---|------|
| 0.0 | 全黑 → 0.8s 淡入背景 |
| 0.4 | 照片 opacity 0→1 + scale 1.03→1.00（600ms，easeOutQuint） |
| 1.2–6.0 | 极缓慢 push-in：照片 scale 1.00→1.035；阴影随之微扩 |
| 3.0 | 右下角极淡地出现 1px 光标点或「加载环」——暗示「即将读取」（opacity 0→0.25） |

**字幕/VO**（可选）
- 3.5s 浮现一行小字居中下三分之一：`一张照片` （opacity 0→1，y +10→0，Medium 24pt）
- 5.0s 该行淡出

**转场**：无硬切。S2 的数据线从照片边缘「长出」即进入下一镜。

**AE 提示**
- 照片层放 `Photo_Main` 预合成，方便后续各镜复用同一 transform 锚点。
- 阴影用 `Drop Shadow` 或预渲染 PNG 阴影板（后者更「苹果」）。

---

### S2 · 参数苏醒（0:06–0:14）

**画面**
- 照片位置不变，略微上移 8% 画幅高，为下方数据区腾出空间。
- 照片上方/周围出现 **6 个数据芯片**（chip），从照片「抽出」：

```
[ Make: SONY ] [ Model: ILCE-7M3 ]
[ Lens: FE 16-35mm F2.8 GM II ]
[ FL: 24mm ] [ f/5.6 ] [ 1/160s ] [ ISO 80 ]
```

- 芯片样式：白底、圆角 12、极轻描边 `#E5E5E7`、键名次级灰、值主文字色。
- 芯片下方一条 1px 引导线连回照片边缘（细线，`#D2D2D7`，2px 端点圆头）。

**动态（核心：数据被「抽取」）**
| t | 动作 |
|---|------|
| 6.0 | 从照片中心发出 6 条细线（scaleX 0→1，沿各自目标方向，400ms） |
| 6.3 | 芯片依次弹出：opacity 0→1 + scale 0.92→1 + y 从照片方向滑入，**stagger 60ms** |
| 7.5 | 芯片内数值打字机/数字滚动：`ISO` 从 0 滚到 80；焦距 `0→24`；光圈 `0→5.6`（300ms easeOut） |
| 9.0 | 引导线收束为一条水平基线，芯片重新排成整齐两行（弹簧归位，500ms） |
| 11.0 | 小标签 `EXIF` 以 mono 字体淡入左上（opacity 0→0.5） |
| 12.5 | 一束 **极淡的高光扫过** 数据行（linear wipe，opacity 0.15 白，600ms）——「读取完成」 |

**文字**
- 可选 Slogan 过渡：`读懂拍摄瞬间`（11s 出现，下方小字，13s 淡出）

**转场** → S3：数据行中的 `Model: ILCE-7M3` 与 `Lens` 芯片 **放大居中**，其余芯片淡出（scale 1→0.96 + blur 0→6 + opacity→0，300ms）。

**AE 提示**
- 芯片用 Shape Layer + Essential Graphics 模板，方便复制。
- 数字滚动用 `#slider` 表达式或 `Numbers` 效果；避免文字层 keyframe 乱跳。
- 引导线用 `Trim Paths`，端点 `Round Cap`。

---

### S3 · 映射翻译（0:14–0:22）

**画面**
- 舞台切至近似「双栏对照」布局（依然极简，不是表格截图）：

```
左（机器）              右（人类）
ILCE-7M3        →      α7 III
FE 16-35mm F2.8 GM II →  FE 16-35mm F2.8 GM II（或短版）
```

- 中间一个细箭头或滑动光带；右侧结果用 **略大字号 + Medium** 强调。
- 背景微暗：`#F5F5F7` → `#ECECEE`（200ms），聚焦视线。

**动态**
| t | 动作 |
|---|------|
| 14.0 | 左侧原始串以 mono 字体滑入（x -20→0） |
| 14.6 | 中轴光带从上到下扫过（linear wipe，400ms） |
| 15.0 | 左串轻微「抖动解析」：opacity 闪烁 2 次（像扫描），每次 80ms |
| 15.6 | **变形**：左串字符位移/交叉溶解到右串（Morph 建议：先 blur+scale 1.05 再清出目标字，350ms）；或用 `CC Scale Wipe` / 手动字符替换 |
| 16.2 | 右串落定弹簧（overshoot 8%） |
| 17.0 | 第二行镜头名同样处理 |
| 18.5 | 底部浮现小字：`相机 / 镜头名称映射 · CSV 可编辑`（次级灰） |
| 20.0 | 两行结果合并为一行最终渲染字符串：<br>`SONY α7 III  |  FE 16-35mm F2.8 GM II` |
| 21.0 | 该字符串缩小飞向照片下方「预留信息位」（与 S4 衔接） |

**转场** → S4：字符串飞行作为 **匹配剪辑（match cut）** 的锚点；照片重新居中放大。

**AE 提示**
- 中英对照的「翻译感」用 **同一文字层换字体/字距** 实现比两个层交叉更干净。
- 若做字符级 morph，建议拆成 2–3 个短语块，勿逐字母（会花）。

### S4 · 样式生长（0:22–0:34）★ 全片高潮 A

**画面**
- 照片居中，占画幅高 ~58%。
- 相框从「无」到「有」的生长过程（以 **底部信息条 Bottom Bars** 或 **信息卡片 InfoCard** 为示范样式）：

**四拍生长**

| 拍 | t | 内容 | 动效 |
|----|---|------|------|
| 1 画布 | 22–24 | 照片周围扩展留白区（背景从纯舞台灰变为「成品画布」），或底部条区域 reveal | `mask` 自下而上 reveal 600ms；照片 scale 微收至 0.97 让出边框 |
| 2 骨架 | 24–26 | 信息条/卡片底板出现（磨砂或纯色条） | opacity 0→1 + height 0→目标（弹簧）；若 InfoCard：blur 20→0 + opacity 0→0.55 白/黑覆层 |
| 3 文字 | 26–30 | 各信息块逐行落位 | **行级 stagger 120ms**：每行 y +14→0 + opacity，easeOutQuint |
| 4 徽章 | 30–34 | 品牌 Logo 淡入 + 曝光四参数胶囊/标签 | Logo：scale 0.9→1 + opacity，400ms；四参数从左到右 stagger 80ms |

**文字落位顺序（建议）**
1. `SONY α7 III  |  FE 16-35mm F2.8 GM II`（主信息行）
2. `FL 24mm` · `Aperture f/5.6` · `Shutter 1/160s` · `ISO 80`
3. `2024.05.23 12:40:18  by  Frank Zhang`（时间/作者）
4. `Piccadilly Circus, London, UK`（地点，若有）
5. 品牌 Logo（右或左，依样式）

**构图注释**
- 成品整体略带「物件感」：可加 1–2° 的极轻微 3D 透视（或纯正视，更苹果）。**推荐纯正视。**
- 24s 时可给信息条一个 300ms 的 **高光扫过**（soft light streak，opacity ≤ 0.2）。

**转场** → S5：成品保持，底部出现一条 **样式切换轨道**（水平胶囊指示器）。

**AE 提示**
- 信息条做成 `Style_BottomBars` 预合成，内部行是独立层，方便 stagger。
- 文字用 `Text Animator`（Position + Opacity）做行级动画，比手动 key 更稳。
- 磨砂卡片：`CC Radial Blur` 或对照片预合成做 `Gaussian Blur` + 覆层，**不要**用 AE 默认粗糙模糊。

### S5 · 一键换装（0:34–0:44）★ 全片高潮 B

**画面**
- 照片**始终不动**（视觉锚点），只有相框样式在变——这是核心信息：**同一张照片，多种表达**。
- 下方一条极简样式选择器：3–4 个圆点或缩略胶囊，当前项用品牌蓝指示条。

**切换序列（4 拍，每拍约 2.2s）**

| t | 样式（建议真实内置名） | 视觉特征 |
|---|------------------------|----------|
| 34 | **信息卡片 InfoCard** | 右下角磨砂圆角卡，金色标签 |
| 36.2 | **参数胶囊 ParamCapsule** | 底部扩展区，四胶囊 + 寄语 |
| 38.4 | **宝丽来风格 Polaroid** | 大留白白框 + 底部手写感寄语区 |
| 40.6 | **简洁信息 SimpleInfo** | 极细信息行，克制排版 |

（可选第 5 拍 42.8s：**胶片夹 FilmClip** / **裁剪胶片 FilmCut**，增加「胶片叙事」。）

**单次换装动效（统一语言）**
1. 旧样式：opacity 1→0 + scale 1→1.02 + blur 0→8，**220ms**
2. 间隙 40ms（全片极少的「空拍」，制造节奏）
3. 新样式：opacity 0→1 + scale 0.98→1 + blur 6→0，**320ms**，弹簧落定
4. 选择器指示条 **水平滑动** 到新位（300ms，easeInOut）
5. 每次换装时，曝光四参数数值 **保持不变**（强调数据来自同一照片）

**文字**
- 34s：顶部小标题 `预设样式 · 即点即换`（每两拍可换副词：`极简` / `胶片` / `卡片` / `胶囊`）
- 42.5s：标题淡出，为 S6 让位

**AE 提示**
- 把每套样式预合成进 `Style_Switcher`，用 **标记（Marker）** 或 **表达式控制的 Index** 切换可见性，避免关键帧地狱。
- 指示条用 `Path` + `Offset Path` 或简单 x position key。
- 若做 5 套，总时长可压到每拍 1.8s，节奏更「苹果发布会」。

### S6 · 随心定制（0:44–0:52）

**画面**
- 保持当前选定样式（建议 InfoCard 或 ParamCapsule，信息量最大）。
- 画面一侧浮现 **2–3 个极简控制「旋钮」**（不是完整 GUI！）：

```
背景  [ 纯黑 | 纯白 | 模糊深 | 模糊浅 ]   ← 一段胶囊开关
字重  [ Light · Book · Medium ]
文字  [ 「City Walk」 ]                  ← 输入框示意
```

**动态**
| t | 动作 |
|---|------|
| 44.0 | 控件从右侧滑入（x +40→0，弹簧），半透明玻璃卡承载（`rgba(255,255,255,0.72)` + blur 20） |
| 45.0 | **背景切换**：点击「模糊深」→ 照片画布背景从纯白/黑 crossfade 到高斯模糊深色（400ms）；文字颜色自动反转（白↔黑，300ms 延迟 100ms） |
| 46.5 | **字重切换**：Medium → Light，字宽/字重 morph 或交叉溶解（250ms） |
| 48.0 | **自定义文字**：打字机输入 `City Walk`（每字 80ms），寄语区同步更新 |
| 49.5 | 控件淡出；成品 **轻微居中放大** scale 1→1.03，停留 1.5s 供「欣赏」 |

**文字旁注**
- 左侧或底部：`全参数可调 · YAML 级掌控`（48.5s 淡入，次级）

**转场** → S7：成品缩小飞向角落或整体淡入深色舞台。

**AE 提示**
- 「自动反转文字色」用两套文字预合成 + 不透明度切换，比表达式取色稳。
- 打字机：`Expression Selector` 或手写 `substr` 表达式。

### S7 · 品牌落版（0:52–0:58）

**动态**
| t | 动作 |
|---|------|
| 52.0 | 深色舞台 opacity 覆盖（250ms） |
| 52.4 | 产品名 y +16→0 + opacity，500ms 弹簧 |

## 4. 动态预演总表（AE 制作用）

### 4.1 全局运动曲线

| 用途 | 曲线 | 时长 |
|------|------|------|
| 入场 | Spring / `0.22, 1, 0.36, 1` | 400–700ms |
| 出场 | `0.4, 0, 1, 1`（easeIn） | 200–350ms |
| 切换 | `0.65, 0, 0.35, 1` | 220–320ms |
| 相机 push-in | 线性或极缓 easeInOut | 跨整镜 |

### 4.3 节奏与音乐点（Beat Sheet）

| 时间 | 画面事件 | 音乐/音效 |
|------|----------|-----------|
| 0:00 | 淡入 | 氛围 pad 起，低通打开 |
| 0:06 | 数据抽出 | 高频轻 tick / soft pop ×6（与芯片同步） |
| 0:15 | 映射变形 | 一次「解析」滤波扫（filter sweep） |
| 0:22 | 画布生长 | 低音 sub 入拍 |
| 0:26–0:30 | 文字落位 | 轻木琴/马林巴点缀（与 stagger 同步） |
| 0:34 | 首次换装 | 明确 beat 进入（120 BPM 左右） |
| 0:34–0:44 | 连续换装 | 每 2s 一个强调 beat |
| 0:44 | 控件滑入 | 音乐略让（drop 一点点） |
| 0:48 | 打字 | 极轻 key sound |
| 0:52 | 落版 | 音乐 resolve + 一次 soft impact |
| 0:58 | 结束 | 尾音 / 1s 淡出 |

**风格**：极简电子 / Apple 发布会式 ambient-tech；避免人声、避免鼓组过满。  
**BPM**：100–120，全片可对齐 2s 一拍（换装段）。

### 4.4 音效清单（微音效，音量 -18dB 左右）

- soft_pop（芯片出现）
- tick（数字滚动）
- whoosh_soft（转场，300ms，忌尖锐）
- switch_click（样式切换，木质/玻璃轻触）
- type_key（打字）
- resolve_chord（落版）
