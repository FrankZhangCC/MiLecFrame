# Logo目录

此目录用于存放用户自定义的Logo文件，这些Logo将可以在MiLeica Frame中使用。

## 文件格式要求

- **格式**: 仅支持PNG格式
- **形状**: 建议为正方形（例如 2048x2048 像素）
- **透明度**: 支持透明背景

## 命名约定

为了支持自动匹配功能，建议按照相机品牌名称命名Logo文件，例如：

- `Canon.png`
- `Sony.png`
- `Nikon.png`
- `Fujifilm.png`
- `Olympus.png`

## 使用方法

1. 将您的Logo文件复制到此目录
2. 在GUI界面中启用Logo功能
3. 选择相应的Logo文件或让系统自动匹配

## 自动匹配

当您上传带有EXIF信息的照片时，系统会尝试根据相机品牌自动匹配相应的Logo文件。

---

**注意**: 确保您的Logo文件是PNG格式且具有足够的分辨率以保证在缩放时的清晰度。
