# Logo目录

此目录用于存放用户自定义的Logo文件，这些Logo将可以在MiLeica Frame中使用。

## 文件格式要求

- **格式**: 仅支持PNG格式
- **形状**: 支持任意长宽比，但建议 ≤ 2.5:1（若竖向则为 1:2.5）以确保最佳视觉效果
- **尺寸**: 系统以短边为基准等比缩放（`logo.size_ratio * 原图长边`），长边自动限制 ≤ `2.5 * size_ratio * 原图长边`
- **透明度**: 必须为 RGBA 透明背景

## 命名约定

为了支持自动匹配功能，建议按照相机品牌名称命名Logo文件，例如：

- `Canon.png`
- `Sony.png`
- `Nikon.png`
- `Fujifilm.png`
- `Olympus.png`

## 使用方法

1. 将您的Logo文件复制到此目录
2. 在GUI界面中启用Logo功能
3. 选择相应的Logo文件或让系统自动匹配

## 自动匹配

当您上传带有EXIF信息的照片时，系统会尝试根据相机品牌自动匹配相应的Logo文件。

---

**注意**: 确保您的Logo文件是PNG格式且具有足够的分辨率以保证在缩放时的清晰度。
