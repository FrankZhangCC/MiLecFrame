【5. 元素布局 info_position】

说明:
  绝对定位元素 = 填写 position / alignment / margin_*
  相对定位元素 = 填写 relative_to / relative_position / alignment / relative_margin
   系统支持的 key: exif, timestamp, timestamp_author, camera, lens, camera_lens, author, location

  ┌─────────────────────────────────────────────────────────────────────┐
  │ 元素1: [______________]  (key)                                       │
  │   定位方式: □ 绝对  □ 相对                                          │
  │   [绝对] position: [______________]  (bottom-left / bottom-right / ...)
  │          alignment: [______________]  (left / center / both-center / right / ...)
  │          margin_top: [____]  margin_bottom: [____]                   │
  │          margin_left: [____]  margin_right: [____]                   │
  │   [相对] relative_to: [______________]                              │
  │          relative_position: [______________]  (below / above / left-of / right-of)
  │          alignment: [______________]  (both-center 等效于 center)    │
  │          relative_margin: [____]  (默认 0.01)                        │
  │          offset_x_ratio: [____]  offset_y_ratio: [____]  (可选, 默认 0)
  ├─────────────────────────────────────────────────────────────────────┤
  │ 元素2: [______________]  (key)                                       │

【6. 预定义文本 defined_texts】（固定内容文本，内容写死在配置中）
  采用补零编号命名：defined_text_01, defined_text_02, ...
  与 info_position 共享同一命名空间，relative_to 可跨区域引用
  每个条目包含 content（文本内容）和标准布局参数

  ┌─────────────────────────────────────────────────────────────────────┐
  │ 文本1 key: [defined_text_01]                                         │
  │   content: [________]  (如: "FL")                                    │
  │   □ 绝对定位  或  □ 相对定位（参数与 info_position 完全相同）        │
  ├─────────────────────────────────────────────────────────────────────┤
  │ 文本2 key: [defined_text_02]                                         │
  │   content: [________]  (如: "shutter")                               │
  │   □ 绝对定位  或  □ 相对定位                                         │
  └─────────────────────────────────────────────────────────────────────┘
